# Hire Ella for Claude

The Claude plugin for [Hire Ella](https://www.sethserver.com/hire-ella/mcp-setup): Ella, an AI assistant who phones
and emails businesses for you.

```
/plugin marketplace add <owner>/<repo>
/plugin install ella-by-sethserver@hire-ella
```

then `/mcp` to sign in to your Hire Ella account. Generated from sethserver.com by scripts/export_ella_plugin.py;
change it there, not here.
